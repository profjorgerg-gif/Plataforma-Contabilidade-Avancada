# Guia Pedagógico — Contabilidade Avançada

Área de materiais exclusivos do Professor.

Estrutura padronizada:

- `metodologia/` — PDFs metodológicos e orientações pedagógicas.
- `slides/` — apresentações/slides de apoio por módulo.

Os arquivos são disponibilizados na interface **Guia Pedagógico** somente ao perfil Professor. A interface está preparada para os materiais oficiais da disciplina. Os PDFs/slides definitivos devem ser adicionados a estas pastas sem alterar o fluxo do aluno.
